## 1. Identify the Harmonics

For a string fixed at both ends, the fundamental frequency occurs when the length of the string ($L$) is equal to exactly half of one wavelength ($\lambda$).



**Formula:**
$$L = \frac{\lambda}{2} \quad \Rightarrow \quad \lambda = 2L$$

---

## 2. Given Values
* **Length ($L$):** $64\text{ cm} = 0.64\text{ m}$ (Converted to SI units)
* **Frequency ($f$):** $330\text{ Hz}$

---

## 3. Calculate Wavelength ($\lambda$)
Using the relationship for the first harmonic:
$$\lambda = 2 \times 0.64\text{ m}$$
$$\lambda = 1.28\text{ m}$$

---

## 4. Calculate Wave Speed ($v$)
We use the standard wave equation:
$$v = f \cdot \lambda$$

**Calculation:**
$$v = 330\text{ Hz} \times 1.28\text{ m}$$
$$v = 422.4\text{ m/s}$$

---

## Final Result
The speed of the wave on this guitar string is **422.4 m/s**.
